# Clay Icons

[![License: CC0-1.0](https://img.shields.io/badge/License-CC0_1.0-lightgrey.svg)](https://creativecommons.org/publicdomain/zero/1.0/)
![Icons](https://img.shields.io/badge/icons-200-blue.svg)

デモやサムネイルで使う、単一テーマのアイコン集です。
アイコンフォルダには、以下の制作ルールを満たした画像だけを収録します。

## 制作ルール

### 内容

- 1 アイコンにつき 1 テーマとする。
- 中央の主役は 1 つだけにする。
- 主役を説明するための小物、風景、バッジ、きらめきなどは追加しない。
- 文字、数字、ロゴ、透かしは入れない。
- 64 px 程度に縮小してもテーマを判別できる、単純で太いシルエットにする。

### 画像とレイアウト

| 項目 | 基準 |
| --- | --- |
| ファイル形式 | PNG（RGBA、透過あり） |
| 画像サイズ | 1024 × 1024 px |
| キャンバス | 正方形、タイル外側は透明 |
| 外枠タイル | キャンバスの約 76〜80%（一辺 約 780〜820 px） |
| 外側の余白 | 各辺 約 100〜120 px を目安に確保 |
| 主役の領域 | キャンバス中央の約 45〜60%を目安に使用 |
| セーフエリア | 主役を外枠タイル内に収め、タイル端へ接触させない |
| ファイル名 | 英小文字の kebab-case（例: `pet-care.png`） |

数値は生成時の目安です。主役の形によって多少前後しても、同じ一覧に並べたときの見た目の大きさと余白を優先します。

### 見た目

- macOS 風の、柔らかなクレイ 3D 表現。
- 大きく丸めた角を持つ、正方形のカラータイル。
- 滑らかなマット素材、柔らかな照明、控えめな接地影。
- 斜め前から見た軽い立体感を基本とする。
- 写実的な質感、ガラス、金属的な反射、細かすぎる装飾は避ける。
- タイル色と主役の色に十分なコントラストを持たせる。

## 共通生成指示

生成時は、概ね次の共通条件を使います。テーマ、中央の主役、タイル色だけをアイコンごとに変更します。

> Square 1024 × 1024 PNG with a genuine transparent background outside the tile. Soft macOS-style clay 3D icon. One icon represents exactly one theme with exactly one central object. No secondary objects, badges, sparkles, scenery, decorations, text, letters, numbers, logos, or watermark. The centered rounded-square tile occupies about 76–80% of the canvas. Keep the object comfortably inside the tile, bold and legible at 64 px. Smooth rounded clay, subtle shadow, simple composition.
